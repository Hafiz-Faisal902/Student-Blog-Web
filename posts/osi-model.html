The OSI Model, explained with things you already know

The Open Systems Interconnection (OSI) Model is a conceptual framework for understanding how networking protocols work together to get data from one device to another. It breaks that whole journey into 7 layers, each with one specific job. Below is each layer, in order, with an everyday comparison for the ones that don't click right away.

  1. 1

    Physical Layer

    Handles the actual connection between devices — sending raw, unprocessed bits over a physical medium.

    Hardware: network cables, repeaters, hubs, and connectors.
  2. 2

    Data Link Layer

    Handles error detection and correction, plus node-to-node data transport, so the bits from the Physical Layer arrive clean.

    Like: traffic lights at an intersection — managing the flow of cars (data) and preventing collisions.
  3. 3

    Network Layer

    Handles data transfer between different networks and works out the best path for data to travel from source to destination.

    Like: a GPS finding the best route from home to school.
  4. 4

    Transport Layer

    Makes sure data gets from the source system to the destination system, managing flow control and error checking along the way.

    Like: a delivery service making sure your package arrives safely and on time.
  5. 5

    Session Layer

    Manages sessions between applications — establishing, maintaining, and ending the connection between devices.

    Like: a phone call — this layer sets up the call, keeps it connected, and ends it when you hang up.
  6. 6

    Presentation Layer

    Translates data between the application layer and the network, formatting and encrypting it so the receiving system can read it.

    Like: a translator converting a book into another language so more people can read it.
  7. 7

    Application Layer

    The layer closest to the end user — it provides network services directly to applications, like email, web browsing, and file transfer.

    Like: a waiter taking your order in a restaurant and bringing you your food.

Stuck remembering the order? There's a classic sentence that maps to Physical → Application, first letter of each word.

"Please Do Not Throw Sausage Pizza Away"

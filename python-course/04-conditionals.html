Conditionals — teaching your program to decide

Every program you've written so far runs top to bottom, no matter what. Conditionals are what let a program actually make a decision — run one block of code if something is true, and a different block if it isn't.

if, elif, else

pythonage = int(input("How old are you? ")) if age >= 18: print("You can vote.") elif age >= 13: print("You're a teenager.") else: print("You're a kid.")

Python checks each condition in order, top to bottom. The moment one is True, it runs that block and skips the rest — so if age is 20, it never even looks at the elif or else.

💡 Trick that will catch you at least once: Python uses indentation (the spaces before a line) to know what belongs inside the if block — there are no curly braces like in some other languages. Mixing tabs and spaces, or forgetting to indent, causes an IndentationError. Most editors handle this automatically once you press Tab, but it's worth knowing why the error exists the first time you see it.

Combining conditions

Sometimes one comparison isn't enough — you need two or more conditions to be true (or just one out of several) at the same time.

  1. 1

    and — both must be true

    The whole condition is only True if every part of it is true.

    age >= 13 and age <= 19 → checks if someone is a teenager
  2. 2

    or — at least one must be true

    Only needs one side to be true for the whole thing to pass.

    day == "Saturday" or day == "Sunday" → checks for a weekend
  3. 3

    not — flips it

    Turns True into False and vice versa.

    not is_raining → True whenever is_raining is False

Nesting conditionals

You can put an if inside another if when one decision only matters after another one's already been made.

pythonmarks = int(input("Enter your marks: ")) if marks >= 40: print("You passed.") if marks >= 90: print("And with distinction!") else: print("You didn't pass this time.")

The distinction check only happens inside the "passed" branch — it never even runs if the person failed, because there's no reason to check.

Putting it together: a grade calculator

pythonmarks = int(input("Enter your marks out of 100: ")) if marks >= 90: grade = "A+" elif marks >= 80: grade = "A" elif marks >= 70: grade = "B" elif marks >= 60: grade = "C" elif marks >= 40: grade = "D" else: grade = "F" print(f"Your grade is: {grade}")
💡 Trick: notice the order — checking from highest to lowest. If you checked marks >= 40 first, every single score above 40 would stop right there and always show "D", since Python stops at the first True it finds. Order matters more than it looks like it should.

What is Python, and why is everyone learning it?

Python is a programming language — a way of giving a computer instructions it can actually follow. What makes Python special is that it reads almost like plain English, which is exactly why it's usually the first language recommended to beginners.

It also happens to run almost everything: websites (Instagram is built on it), data analysis, AI and machine learning, automation scripts, even games. Learning it isn't just a school exercise — it's a genuinely useful skill.

Step 1: Installing Python

Before writing any code, you need Python installed on your computer.

  1. 1

    Download it

    Go to python.org/downloads and download the latest version for your operating system (Windows, Mac, or Linux).

  2. 2

    Run the installer

    On Windows, there's a checkbox during install that says "Add Python to PATH" — tick it. This one checkbox saves you a lot of confusion later, since it lets you run Python from anywhere on your computer.

  3. 3

    Check it worked

    Open Command Prompt (Windows) or Terminal (Mac), type the command below, and press Enter. If you see a version number, you're set.

    terminalpython --version

Step 2: Your first line of code

Every programmer's first program does the exact same thing: it prints a message to the screen. Open a new file, save it as hello.py, and type this:

hello.pyprint("Hello, world!")

Run it from your terminal with python hello.py, and you should see Hello, world! printed out. That's it — you're officially a programmer now.

💡 Trick: you don't need a fancy setup to start. A free tool called Thonny (thonny.org) gives you an editor and a "Run" button in one window — no terminal commands needed. Great for your first few lessons if typing terminal commands feels intimidating right now.

A quick note on comments

Anything after a # symbol is a comment — Python ignores it completely. Comments are just notes for humans reading the code (including future-you).

python# This line does nothing — it's just a note print("This line actually runs")

That's the whole first lesson. In Lesson 2, we'll start actually storing information using variables.

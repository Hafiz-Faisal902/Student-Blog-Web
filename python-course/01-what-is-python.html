What is Python, and why is everyone learning it?

Before touching any code, let's actually answer the question: what does it mean to "write a program"? At the most basic level, a computer only ever does what it's told, step by step. A programming language is just a way to write those steps down in a form the computer can follow — and Python is one of those languages.

What makes Python different from a lot of other languages is that it was deliberately designed to look close to plain English. A line like if age > 18: reads almost like a sentence, which is exactly why it's usually the first language recommended to complete beginners — you spend your energy learning to think like a programmer, not decoding confusing symbols.

It's also not just a "beginner" language you'll outgrow. Instagram, Spotify's backend, and huge parts of AI and machine learning research are all built on it. Learning it isn't just a class requirement — it's the same language powering things you probably already use every day.

Step 1: Installing Python

Before writing any code, you need Python installed on your computer. This only takes a few minutes.

  1. 1

    Download it

    Go to python.org/downloads and download the latest version for your operating system (Windows, Mac, or Linux). The website automatically detects your system and shows the right download button.

  2. 2

    Run the installer

    On Windows, there's a checkbox during install that says "Add Python to PATH" — tick it before clicking Install. This one checkbox is what lets you type python from any folder on your computer later. If you miss it, you can usually reinstall and just tick it the second time — nothing is broken permanently.

  3. 3

    Check it worked

    Open Command Prompt (Windows) or Terminal (Mac), type the command below, and press Enter. If you see a version number like Python 3.12.1, you're set.

    terminalpython --version
💡 Trick: if python --version says "command not found" even after installing, the PATH checkbox from Step 2 is almost always the reason. On Windows, try py --version instead — Windows sometimes installs Python under the shorter py command. It's not a sign you did anything wrong; this trips up almost everyone the first time.

Don't want to deal with the terminal at all right now? A free tool called Thonny (thonny.org) gives you a simple window with a "Run" button — no terminal commands needed. Totally fine to start here and move to the terminal later once it feels less unfamiliar.

Step 2: Your first line of code

Every programmer's first program does the exact same thing: it displays a message on the screen. Open a new file, save it as hello.py, and type this:

hello.pyprint("Hello, world!")

Let's actually break down what's happening in that single line, piece by piece, because every part of it matters:

  • print is a function — think of it as a tool that Python already comes with built in. You're not building the ability to show text on screen from scratch; you're just using a tool that's already there.
  • The ( ) parentheses are how you hand something to that tool. Whatever goes inside them is what print will actually display.
  • The " " quotation marks tell Python "this is text, not code" — we'll cover exactly why that matters in the next lesson.

Run it from your terminal with python hello.py (or press Run in Thonny), and you should see Hello, world! appear. That's it — you're officially a programmer now.

print() isn't just for text

You can print numbers too, without quotes around them:

pythonprint("My favorite number is:") print(7)

Notice 7 has no quotes — that's because it's being treated as an actual number, not text. This distinction — text vs. number — is exactly what Lesson 2 is about.

A quick note on comments

Anything after a # symbol is a comment — Python completely ignores it. Comments are notes written for humans reading the code later, including future-you re-reading your own program in three months and wondering what you were thinking.

python# This line does nothing — it's just a note print("This line actually runs")

*****

Exercise 3 — Break it on purpose

Take your hello.py file and delete just the closing quotation mark, so it reads print("Hello, world!). Run it. Read the error message Python gives you, word for word — don't just skim past it.

You should see something like SyntaxError: unterminated string literal. Don't panic at error messages — Python is actually telling you exactly what's wrong and often the line number too. Learning to read errors calmly, instead of assuming everything's broken, is one of the most useful skills in this entire course.

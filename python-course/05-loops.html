Loops — making Python repeat itself

Say you wanted to print "Hello" five times. You already know enough to do this:

pythonprint("Hello") print("Hello") print("Hello") print("Hello") print("Hello")

That works, but it's clumsy — and completely falls apart the moment you need to print it 1,000 times, or a number that isn't known until the program is actually running. A loop is how you tell Python "repeat this block of code," without writing it out over and over yourself.

The for loop

A for loop repeats a block of code once for every item in a sequence. The most common sequence to loop over is a range of numbers, using the built-in range() function.

pythonfor i in range(5): print("Hello")

This prints "Hello" exactly 5 times. i is just a variable name — you'll see i used constantly by convention (short for "index"), but you could call it anything. Each time through the loop, i takes the next value Python gives it, and the indented block runs once for that value.

💡 The trap almost everyone falls into first: range(5) gives you 0, 1, 2, 3, 4 — five numbers, starting at 0, and stopping before 5. It does not include 5 itself. This trips up nearly every beginner at least once. Try it and see for yourself:
pythonfor i in range(5): print(i) # Output: 0 1 2 3 4 — never 5

range() with a start and a step

range() can take up to three numbers: range(start, stop, step).

  1. 1

    One number: range(stop)

    Starts at 0, goes up to (but not including) stop.

    range(5) → 0, 1, 2, 3, 4
  2. 2

    Two numbers: range(start, stop)

    Starts wherever you say, still stops before stop.

    range(2, 6) → 2, 3, 4, 5
  3. 3

    Three numbers: range(start, stop, step)

    The third number controls how much it jumps by each time — including going backwards with a negative step.

    range(0, 10, 2) → 0, 2, 4, 6, 8  ·  range(5, 0, -1) → 5, 4, 3, 2, 1

Looping directly over a string

You're not limited to looping over numbers — you can loop over the individual characters in a string too, without needing range() at all:

pythonfor letter in "Python": print(letter) # Output: P, y, t, h, o, n — one per line

The while loop

A for loop is great when you know how many times you want to repeat something. A while loop repeats as long as a condition stays True — useful when you don't know the exact number of repeats in advance, like "keep asking until they type the right password."

pythoncount = 0 while count < 5: print("Hello") count += 1

count += 1 is shorthand for count = count + 1 — it just adds 1 to whatever count already is. This line is doing the real work here: without it, count would stay 0 forever, and the condition count < 5 would never become false.

⚠️ The single most common while-loop mistake: forgetting to update the thing your condition checks, creating an infinite loop that never stops on its own. If your program looks completely frozen after running a while loop, this is almost always why. Press Ctrl + C in the terminal to force it to stop, then go check that whatever's in your condition is actually changing inside the loop.

break — exit a loop early

break immediately stops the loop, even if its condition would still technically allow it to continue. Common use: searching for something and stopping the moment you find it.

pythonwhile True: password = input("Enter the password: ") if password == "python123": print("Access granted.") break print("Wrong password, try again.")

while True: creates a loop that would normally run forever, since True is never going to become false on its own — this is intentional here, and break is what actually gives it an exit door once the right condition happens.

continue — skip just this one round

continue skips the rest of the current pass through the loop and jumps straight to the next one, instead of stopping the loop entirely.

pythonfor i in range(1, 11): if i % 2 == 0: continue print(i) # Prints only the odd numbers 1–9

Every time i is even, continue skips the print(i) line for that round and moves straight to the next value of i — the loop itself keeps running, just that one round gets cut short.

Nested loops

A loop can contain another loop inside it. The inner loop runs completely, start to finish, for every single pass of the outer loop.

pythonfor i in range(1, 4): for j in range(1, 4): print(f"{i} x {j} = {i * j}")

For every value of i (1, 2, then 3), the inner loop runs all the way through j (1, 2, 3) before moving to the next i — that's 3 × 3 = 9 total lines printed, not 3 + 3.

The accumulator pattern

One of the most useful loop patterns in all of programming: using a loop to build up a running total, one step at a time.

pythontotal = 0 for number in range(1, 101): total += number print(f"Sum of 1 to 100: {total}")

total starts at 0, and on every pass through the loop, whatever number we're currently on gets added to it. By the time the loop finishes, total holds the sum of every number it saw along the way. This exact pattern — start at zero, add something each round — comes up constantly, in problems that don't look anything like "add up some numbers" on the surface.

Exercise 4 — while loop with break

Write a program that keeps asking "Guess the secret number (between 1 and 5):" until the person guesses 3 correctly, then prints "Correct!" and stops.

pythonwhile True: guess = int(input("Guess the secret number (between 1 and 5): ")) if guess == 3: print("Correct!") break print("Wrong, try again.")
Exercise 5 — Challenge: nested loops

Print a triangle of stars, 5 rows tall, where each row has one more star than the last:

*
**
***
****
*****
pythonfor i in range(1, 6): print("*" * i)

Sneaky shortcut: "*" * i repeats the string "*" a total of i times — Python lets you multiply a string by a number. No inner loop needed for this particular version, though writing it with a proper nested loop (printing one star at a time) works too and is a great thing to try on your own.

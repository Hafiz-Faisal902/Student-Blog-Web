Variables & data types

In Lesson 1, we printed things directly: print("Hello, world!"). That works fine for a message that never changes. But almost every real program needs to store information and reuse it — a username, a score, a temperature — often changing it as the program runs. That's what a variable is for.

What a variable actually is

Think of a variable as a labeled box. You write a label on it (the variable's name), put something inside (the value), and from then on, you can just refer to the box by its label instead of repeating the value itself.

pythonname = "Hafiz" age = 16 print(name) print(age)

Here, name and age are variables. The = sign doesn't mean "equals" like in a math equation — it means "store this value in this box." Read name = "Hafiz" in your head as "name gets the value Hafiz," not "name equals Hafiz."

Variables can change

The label stays, but what's inside the box can be replaced any time — that's the entire point of calling it a "variable" and not a "constant."

pythonscore = 0 print(score) score = 10 print(score)

This is genuinely one of the most useful ideas in this whole course — a running total, a health bar in a game, a countdown timer — all of that is really just one variable being updated over and over.

💡 Trick: variable names can't start with a number or contain spaces, but underscores work — write student_name, not student name. Python is also case-sensitive: Age and age are two completely different variables, which is a sneaky source of bugs when you accidentally mix the capitalization.

The core data types

Every value in Python has a type — it tells Python what category of thing it's dealing with, which affects what you're allowed to do with it. This is exactly why the quotation marks in Lesson 1 mattered.

  1. 1

    int (integer)

    Whole numbers, positive or negative, no decimal point. Use this for anything you count in whole units — age, number of students, a score.

    age = 16
  2. 2

    float (decimal number)

    Numbers with a decimal point — anything that needs more precision than a whole number gives you, like a height or a price.

    height = 5.9
  3. 3

    str (string)

    Text, always wrapped in quotes — single or double, Python doesn't mind which, as long as the opening and closing quote match. This is exactly what Lesson 1's Exercise 3 broke on purpose.

    name = "Hafiz"
  4. 4

    bool (boolean)

    Only two possible values: True or False — always capitalized, no quotes. These exist specifically for yes/no, on/off situations, and we'll rely on them heavily starting in Lesson 4.

    is_student = True

Checking a variable's type

Not sure what type something is? Ask Python directly with the built-in type() function — handy while you're still building an instinct for which type is which.

pythonage = 16 print(type(age)) # Output: <class 'int'>

Mixing types (and why it breaks)

Python won't let you combine a number and text with + — this is one of the most common errors every beginner hits, so it's worth causing on purpose right now so it's familiar later:

pythonage = 16 print("I am " + age) # TypeError: can only concatenate str (not "int") to str

Python isn't being difficult here — it genuinely doesn't know what you mean by "text plus a number." Do you want "16" stuck onto the end of the sentence, or something else entirely? The fix is to be explicit and convert the number into a string first, using str():

pythonage = 16 print("I am " + str(age)) # Output: I am 16
💡 Trick: there's a cleaner way to mix text and variables — an f-string. Put an f right before the opening quote, and drop variables straight in using curly braces. No str() needed, and it reads much closer to a normal sentence. We'll use these constantly from here on:
pythonage = 16 print(f"I am {age} years old")

🧩 Practice

Exercise 1 — Easy

Create three variables: your name, your age, and your favorite subject. Print a single sentence using an f-string that uses all three, like: "My name is Hafiz, I'm 16, and I like Computer Science."

pythonname = "Hafiz" age = 16 favorite_subject = "Computer Science" print(f"My name is {name}, I'm {age}, and I like {favorite_subject}.")
Exercise 2 — Fix the bug

This code crashes. Figure out why, then fix it without changing what it's trying to print:

pythonprice = 250 print("The price is $" + price)

It's the same string-plus-number error from this lesson. Two valid fixes:

python (fix 1)price = 250 print("The price is $" + str(price)) python (fix 2 — cleaner)price = 250 print(f"The price is ${price}")
Exercise 3 — Predict before you run

Without running this, write down what type() will print for each line. Then actually run it and check yourself.

pythonprint(type(5)) print(type(5.0)) print(type("5")) print(type(True))

<class 'int'>, <class 'float'>, <class 'str'>, <class 'bool'> — note that "5" in quotes is text, not a number, even though it looks like one to us.

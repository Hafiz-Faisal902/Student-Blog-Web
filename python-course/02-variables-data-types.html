Variables & data types

A variable is just a labeled box that stores a value so you can use it later. Instead of typing the same value over and over, you give it a name once, and Python remembers it.

pythonname = "Hafiz" age = 16 print(name) print(age)

Here, name and age are variables. The = sign doesn't mean "equals" like in math — it means "store this value in this box."

💡 Trick: variable names can't start with a number or contain spaces, but you can use underscores instead — write student_name, not student name. Python is also case-sensitive: Age and age are two completely different variables.

The core data types

Every value in Python has a type — it tells Python what kind of thing it's dealing with, so it knows what you're allowed to do with it.

  1. 1

    int (integer)

    Whole numbers, positive or negative, no decimal point.

    age = 16
  2. 2

    float (decimal number)

    Numbers with a decimal point — used for anything that isn't a whole number.

    height = 5.9
  3. 3

    str (string)

    Text, always wrapped in quotes — single or double, Python doesn't mind which, as long as they match.

    name = "Hafiz"
  4. 4

    bool (boolean)

    Only two possible values: True or False. Used constantly for decisions — we'll use these a lot in Lesson 4.

    is_student = True

Checking a variable's type

Not sure what type something is? Ask Python directly with the built-in type() function.

pythonage = 16 print(type(age)) # Output: <class 'int'>

Mixing types (and why it can break)

Python won't let you combine a number and text with + — this is one of the most common beginner errors, so it's worth seeing on purpose now:

pythonage = 16 print("I am " + age) # TypeError: can only concatenate str (not "int") to str

The fix is to convert the number to a string first, using str():

pythonage = 16 print("I am " + str(age)) # Output: I am 16
💡 Trick: there's a cleaner way to mix text and variables — an f-string. Put an f right before the quotes, and drop variables straight in with curly braces. No str() needed. We'll use these constantly from here on:
pythonage = 16 print(f"I am {age} years old")

That covers the core building block of every Python program. In Lesson 3, we'll get input directly from the person running the program, and use operators to actually do something with it.

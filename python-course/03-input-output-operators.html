Input, output & operators

So far, every value in our programs has been typed directly into the code. Real programs need to react to whatever the person running them types in — that's what this lesson is about.

Getting input from the user

The input() function pauses the program, waits for the person to type something and press Enter, then hands you back whatever they typed.

pythonname = input("What's your name? ") print(f"Hello, {name}!")
💡 Trick that trips up almost every beginner: input() always gives you back a string — even if the person types a number. Try this and see what happens:
pythonage = input("How old are you? ") print(age + 5) # TypeError: can only concatenate str (not "int") to str
Fix it by wrapping the input in int() (or float() for decimals):
pythonage = int(input("How old are you? ")) print(age + 5)

Operators

Operators are the symbols that actually do things to your values. Most of these you already know from math class — a couple are new.

  1. 1

    The basics: + − * /

    Addition, subtraction, multiplication, and regular division. Nothing surprising here.

    7 + 3 → 10  ·  7 / 2 → 3.5
  2. 2

    // — floor division

    Divides, then drops everything after the decimal point. Useful whenever you want a whole-number result and don't care about the remainder.

    7 // 2 → 3
  3. 3

    % — modulus (the remainder)

    Gives you what's left over after dividing. This one shows up constantly — it's the standard way to check if a number is even or odd.

    7 % 2 → 1  ·  8 % 2 → 0
  4. 4

    ** — exponent (power)

    Raises a number to a power. Not the same as ^, which does something different in Python.

    2 ** 5 → 32
  5. 5

    Comparison operators

    These compare two values and give back True or False — we'll lean on these heavily starting next lesson.

    5 == 5 → True  ·  5 != 3 → True  ·  5 > 10 → False
💡 Trick: a single = assigns a value ("store this"). A double == checks equality ("are these the same?"). Mixing them up is one of the most common bugs in every beginner's first week — including mine.

Putting it together: a tiny calculator

Here's everything from this lesson combined into a program that actually does something:

pythonnum1 = float(input("Enter first number: ")) num2 = float(input("Enter second number: ")) print(f"Sum: {num1 + num2}") print(f"Difference: {num1 - num2}") print(f"Product: {num1 * num2}") print(f"Quotient: {num1 / num2}")

That's genuinely a working calculator in eight lines. In Lesson 4, we'll use those comparison operators to make programs that actually make decisions instead of just running top to bottom.

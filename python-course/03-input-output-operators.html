Input, output & operators

Every program you've written so far has the exact same values typed directly into the code. Run it a hundred times, get the exact same result every time. Real programs need to react to whatever the person actually typed in on that specific run — that's what this lesson unlocks.

Getting input from the user

The input() function pauses your program completely, waits for someone to type something and press Enter, and then hands that text back to you as a value you can store.

pythonname = input("What's your name? ") print(f"Hello, {name}!")

Whatever's inside the parentheses — "What's your name? " here — is just a message shown to the person before they type, called a prompt. It's optional, but leaving it out means they'll just see a blinking cursor with no idea what you're asking for.

💡 The trap almost everyone falls into: remember Lesson 2's Exercise 3, where you predicted type("5")? input() works the exact same way — it always gives you back a string, even if the person types numbers. Try this and see what happens:
pythonage = input("How old are you? ") print(age + 5) # TypeError: can only concatenate str (not "int") to str
Same fix as before — wrap it in int() (or float() for decimals) to convert it:
pythonage = int(input("How old are you? ")) print(age + 5)

Operators

Operators are the symbols that actually do things with your values. Most of these are already familiar from math class — a couple are genuinely new, and they're the ones worth slowing down for.

  1. 1

    The basics: + − * /

    Addition, subtraction, multiplication, and regular division — behaves exactly like a calculator.

    7 + 3 → 10  ·  7 / 2 → 3.5
  2. 2

    // — floor division

    Divides, then throws away everything after the decimal point — it doesn't round, it just cuts it off. Useful any time you want a whole-number answer, like figuring out how many full teams of 4 you can make from 22 people.

    22 // 4 → 5 (5 full teams, 2 people left over)
  3. 3

    % — modulus (the remainder)

    Gives you what's left over after dividing — in the teams example above, that's the 2 leftover people. This one shows up constantly in real code: it's the standard way to check whether a number is even or odd, since any number divided by 2 either leaves 0 or 1 remaining.

    22 % 4 → 2  ·  8 % 2 → 0 (even)  ·  7 % 2 → 1 (odd)
  4. 4

    ** — exponent (power)

    Raises a number to a power. Not the same as ^, which does something completely different in Python (it's a rarely-used bitwise operator — safe to ignore for now).

    2 ** 5 → 32
  5. 5

    Comparison operators

    These compare two values and give back True or False instead of a number — a boolean, from Lesson 2. We'll build heavily on this starting next lesson.

    5 == 5 → True  ·  5 != 3 → True  ·  5 > 10 → False
💡 Trick: a single = assigns a value ("store this," from Lesson 2). A double == checks equality ("are these the same?"). They look almost identical and do completely different things — mixing them up is one of the most common bugs in every beginner's first month, including mine.

Putting it together: a tiny calculator

Here's everything from this lesson combined into a program that actually does something useful:

pythonnum1 = float(input("Enter first number: ")) num2 = float(input("Enter second number: ")) print(f"Sum: {num1 + num2}") print(f"Difference: {num1 - num2}") print(f"Product: {num1 * num2}") print(f"Quotient: {num1 / num2}")

That's a genuinely working calculator in eight lines — take a second to actually run it before moving on.

🧩 Practice

Exercise 1 — Easy

Write a program that asks the user for their name and their favorite number, then prints: "Nice to meet you, [name]! [number] is a great number." Watch out for the type of the number you get back from input().

pythonname = input("What's your name? ") number = input("What's your favorite number? ") print(f"Nice to meet you, {name}! {number} is a great number.")

Note: you don't actually need to convert number to an int here — you're only printing it inside an f-string, not doing math with it, so a string works perfectly fine.

Exercise 2 — Predict the output

Without running it, work out what each line prints:

pythonprint(17 // 5) print(17 % 5) print(2 ** 4) print(10 == 10.0)

3 (17 divided by 5 is 3 whole times), 2 (2 left over), 16, True — Python treats 10 and 10.0 as equal in value even though one's an int and the other's a float.

Exercise 3 — Build it

Write a program that takes a whole number of minutes as input, and prints how many full hours and leftover minutes that equals. Example: 130 minutes should print "2 hours and 10 minutes."

pythontotal_minutes = int(input("Enter total minutes: ")) hours = total_minutes // 60 leftover_minutes = total_minutes % 60 print(f"{hours} hours and {leftover_minutes} minutes")

Now our programs can react to real input and do actual math with it. In Lesson 4, we'll use those comparison operators from earlier to make programs that respond differently depending on what happens — real decision-making, not just running top to bottom.
